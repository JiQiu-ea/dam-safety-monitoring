# 大绩水库大坝安全监测平台

河海大学智慧水利课程作业 · 小组「TFBOYS」 · 本阶段交付：**静态首页 `index.html`**

大绩水库位于福建省龙岩市武平县中堡镇大绩村，是一座以城镇供水为主、兼顾农田灌溉与下游防洪的小（1）型水库（总库容约 230 万 m³，主坝为最大坝高 40 m 的混凝土重力坝，副坝为最大坝高 7 m 的均质土坝）。本项目为其建设一个静态首页，把工程概况与大坝渗流、水位监测数据集中展示，为后续功能开发打基础。

## 目标用户与主要功能

| 目标用户 | 主要用途 |
| --- | --- |
| 水库管理所值班员 | 每日掌握库水位与各测点渗流状态 |
| 工程科技术负责人 | 判断测点数据是否异常、安排复核 |
| 上级水利/防汛监管部门 | 检查工程运行与数据公开情况 |
| 运维人员 | 对照测点位置与状态进行检修 |

**本阶段主要功能（只读展示，无后端）**

- 顶部导航四项锚点：工程概况 / 实时监测 / 历史数据 / 关于我们
- 「工程概况」区块：工程特性参数表、大坝图片
- 「实时监测」区块：六列监测数据表（监测点名称、监测类型、渗流量(L/s)、水位(m)、更新时间、状态）
- 数据缺失时状态显示「暂无数据」，渗流量与水位列显示「—」，**不以 0 或虚构读数代替**
- 页脚注明数据来源与更新规则

**本阶段范围之外**（留待后续迭代）：后端服务、数据库、数据录入与表单提交、JavaScript 交互、指挥大屏、AI 识别、告警推送。

## 首页打开方法

不需要安装任何环境：**双击 `index.html`**，或右键选择浏览器打开即可。

- 建议使用 Chrome / Edge
- 页面为单文件静态页，样式内联在 `<head>` 的 `<style>` 中，**不依赖任何外部框架或 CDN**
- 若需图文完整显示，请确保 `assets/` 目录与 `index.html` 已一并下载
